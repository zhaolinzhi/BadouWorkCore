# Badou 企业附加规则 — requesting-code-review

Write your Badou enterprise rules in this file in any language
(typically Chinese).

Workflow to make these rules take effect:

1. Edit this file (`.badou-local.md`) with your rules in any language.
2. Ask Claude to translate it to English and write to
   `.badou-local.en.md`.
3. Run: `python3 .claude/badou-coding-sync.py --version 6.0.0`
4. In Claude Code, run `/reload-plugins`.

Only the content BELOW the marker line is treated as your rules.
Everything above (including this stub) is for the editor and is not
copied into SKILL.md.

**IMPORTANT**: Do NOT write any 'hint' or 'note' (e.g. 'this file
is auto-injected into SKILL.md') BELOW the marker line. Only your
real business rules belong there — anything else gets translated
and injected into SKILL.md as noise to the agent. Put all such
editor-facing notes ABOVE the marker (in this stub section).
